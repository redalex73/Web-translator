# Web-translator

Una aplicación ligera de traducción web desarrollada en Python.  
Ingresa la URL de una página web, selecciona el idioma al que deseas traducirla y pulsa “Traducir” para obtener el contenido traducido.

---

## 🚀 Características principales

- Traducción de páginas completas desde una URL.  
- Interfaz gráfica simple (GUI) con selección de idioma de origen y destino.  
- Implementada con módulos de Python para automatización y procesamiento de texto.  
- Ideal como demo de automatización de traducciones, integración multilingüe o base para servicios de localización.

---

## 🧰 Tecnologías usadas

- Python  
- Librerías de traducción (por ejemplo: `googletrans`, `deep_translator` u otras)  
- `Tkinter` para la interfaz gráfica (GUI)  
- Scripts de procesamiento de texto y extracción de contenido web (`translator.py`, `main.py`, `gui.py`)
